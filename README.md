# Driver's Eye Detection
Real-time eye detection using Python and OpenCV. Detects eyes in images, webcam feeds, or videos with bounding boxes. Perfect for computer vision experiments and hackathons.

## Features
- Live webcam eye tracking.
- Image/video input support.
- Haar cascade-based detection for speed.
- Adjustable detection thresholds.

## Tech Stack
- Python 3.x
- OpenCV (cv2)
- NumPy

## Quick Start
1. Clone repo:
   ```bash
   git clone https://github.com/Rishav-2310/Eye-Detection.git
   cd Eye-Detection
   ```
2. Install deps:
   ```bash
   pip install opencv-python numpy
   ```
3. Run:
   ```bash
   python eye_detection.py
   ```
